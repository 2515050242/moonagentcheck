# MoonAgentCheck 0.3.0

发布日期：2026-10-21。许可证：Apache-2.0。发布账号：`2515050242`。

[Mooncakes 版本页](https://mooncakes.io/docs/2515050242/moonagentcheck@0.3.0) · [仓库主页](https://github.com/2515050242/moonagentcheck) · [验收复现指南](../acceptance-guide.md)

## 十月新增

- Responses 混合项：仅跳过明确支持的 message / reasoning；未支持类型保留输入索引并阻止通过。
- 未知结果：`completed` 缺少明确执行器 outcome 时产生 `unknown-result` / `AGC018`，报告 `passed: false`。
- MoonBit JSON 示例入口：解析输入，调用实际适配器和核心评估器，返回结构化 JSON；非法输入返回失败报告。
- Python 接入：5 个 fixture 通过子进程调用 MoonBit CLI 并断言报告，不独立实现评估规则。
- 发布包消费：固定依赖 `0.3.0`，直接调用安装包的 Responses API，解析并核对正常成功及未知结果拒绝的完整状态、规则码与事件位置。

## 安装与验证

```sh
moon add 2515050242/moonagentcheck@0.3.0
```

在 `moon.pkg` 中导入 `2515050242/moonagentcheck/src`。可参考仓库的 `examples/mooncakes-consumer`：CI 将该样例复制到仓库以外，通过 registry 构建和运行 2 项测试，避免误用本地源码。

源码验证使用 `moonc v0.10.16+b1a0e846e`，包含 96 项 MoonBit 测试、无参演示和 5 个 Python→MoonBit fixture；消费方的 2 项测试单独计数。CI 分别执行源码、Python 接入和发布包消费检查。格式、构建、静态检查均须成功；保留的弃用提示不应被表述为零警告。

## 范围与来源

核心库不运行 Agent，不连接模型、网络或真实工具；示例输入均为合成遥测。`operation_id` 和 outcome 由应用侧提供，不声称为 API 原生字段。未提供真实框架集成或性能优势承诺。

原创实现，参考公开接口字段，见[来源说明](../provenance.md)。项目目标和功能边界由参赛者提出；AI 辅助实现、回归整理和文档校对，验证结果由公开命令及 CI 支持。

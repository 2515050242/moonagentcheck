# 决策记录 0012：未知工具结果必须失败关闭

## 背景

Responses 的 `completed` 表示输出项已完成，不代表工具执行成功。适配器会将缺少执行器观测结果的 output 保留为 `ok: null`。在已有实现中，这种状态虽然不是成功，但单独出现时没有产生违规，归档报告可能因此显示通过。

## 决策

将未知结果作为独立契约违规 `unknown-result`（`AGC018`）。它与 `missing-result` 区分：前者表示观察到了 result，但结果状态未知；后者表示调用结束时没有可关联的 result。诊断级别为错误，任何包含未知结果的评估都不能通过。

## 验证

MoonBit 核心测试、诊断摘要测试和 Responses 归档报告测试分别验证未知结果会产生 `AGC018`、错误诊断和 `passed: false`。Python 离线 fixture 同步覆盖相同的适配边界。

## 范围

此决策只调整离线事件评估和报告，不推断工具是否实际执行，也不添加 Responses 客户端、网络请求或 Agent runtime。接入方仍需从执行器提供明确的成功或失败结果。

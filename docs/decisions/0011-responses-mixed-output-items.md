# 决策记录 0011：明确处理 Responses 混合输出

## 背景

Responses 输出序列可以同时包含消息、推理内容和函数调用。MoonAgentCheck 只验证工具行为；如果把每一项都转换成工具事件，会产生错误判断；如果忽略所有未识别类型，又可能把未支持的工具项漏掉。

## 决策

- 调用方可通过 `responses_non_tool_item(...)` 显式传入非工具项；当前只接受 `message` 和 `reasoning`。
- 这两类项目不生成 `Event`，也不改变函数调用与结果的关联。
- 其他类型产生带原始 `item_index` 的映射问题，不静默通过。
- 调用方仍按原始顺序传入已提取的字段；该适配层不解析 JSON、不访问 API，也不执行工具。

## 取舍

显式识别少量非工具类型，避免把未知内容解释成安全或成功；同时保留轻量、确定性的事件模型。增加其他非工具类型前，先确认其字段语义并加入对应回归用例。

# 决策记录 0002：先交付可审查证据

## 背景

Agent 项目很容易把范围扩大到运行时、模型调用、工具协议和云端界面。这样虽然功能看起来丰富，但在黑客松截止时间内很难证明行为正确，也容易和 MoonBit 生态中已有项目重合。

## 决策

MoonAgentCheck 先实现一个小而完整的证据链：

```text
事件输入 → 确定性评估 → 违规记录 → MoonBit 测试 → CI
```

每个规则都必须同时有：

- 一个明确的事件关系；
- 一段 MoonBit 实现；
- 一个可执行测试；
- 一条 README 或行为契约说明。

## 结果

项目可以在没有模型、网络和真实工具的情况下完成回归验证。后续 adapter 和 JSON 报告都围绕这条证据链扩展，而不是改变核心职责。

# 决策记录 0004：写入完成必须匹配原始调用身份

## 背景

`write-complete` 用来证明已成功调用工具后的副作用已落地。先前评估器只验证它的 `call_id` 已有成功 result；如果接入层把工具名或业务操作 ID 填错，事件仍会被当作合法写入，错误地把一个工具的成功借给另一个工具或逻辑操作。

## 决策

当 `write-complete` 引用了已知调用时，同时比较它的 `tool` 和 `operation_id` 与该 call。任何不一致报告稳定规则 `write-call-mismatch`（`AGC016`）。这条规则只验证已经提交的离线事件，不试图推断真实写入内容或执行工具。

## 取舍

调用 ID 仍是关联主键，工具名和业务操作 ID 是防止适配器串线的证据字段。缺失 `operation_id` 继续由既有 `missing-operation-id` 规则报告；本规则不会将文本相同的两个独立写入视为重复，也不引入新的权限或运行时系统。
